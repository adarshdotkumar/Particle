particle-fieldhero example

Text sits on top

The canvas is transparent and ignores the pointer.

Container mode

The effect is scoped to its <div>: it sizes to that box via a ResizeObserver, tracks the cursor relative to that box, and pauses itself when you scroll it out of view. Nothing here touches the window.

A second, independent field

Different shape, different colours, its own simulation.

Scroll-driven assembly

Pass "progress": "scroll" and the shape assembles as the element crosses the middle of the viewport, then comes apart again as it leaves.

Run npm run build:lib first — this page loads the real dist/particle-field.min.js, three.js included, no import map.
